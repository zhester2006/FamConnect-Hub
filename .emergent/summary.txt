**PRODUCT REQUIREMENTS:**
-   **Profiles:** Customizable parent and child profiles.
-   **Dashboards:**
    -   **Child (Space):** Chores, tasks, events, awards, leaderboard, points, item request system, calendar events.
    -   **Parent:** View all child info, approve requests (items, chore swaps), view daily/weekly events, manage chores, modify points.
    -   **Home Hub:** A main dashboard for large screens displaying a calendar, family wall, events, weather, date/time on a single, non-scrollable screen.
-   **Core Features:**
    -   **Calendar:** Main page with day/week/month views. Displays events (with time and type) and work schedules. Clicking a day shows a pop-up with that day's events.
    -   **Chores:** AI-assisted automated scheduling, parent modification, penalty for missed chores, bye day system, chore swapping, ability for parents to omit children from certain chores and modify points.
    -   **Live Chat:** Instant messenger with a layout similar to Facebook Messenger.
    -   **Family Wall:** A shared space for messages, photos, polls. Features a sticky input box for new posts. AI-generated daily inspirational quotes.
    -   **Shopping List:** Items requested by children or added by parents, visible on the Home Hub.
    -   **Points & Rewards:** Earn points for chores/tasks, view on a leaderboard. Parents can add/modify items and points in a Rewards Shop.
    -   **Reading Log:** Children submit book title and summary for parent approval.
    -   **Dinner Planner:** AI-suggested meals.
-   **Technical & UX Requirements:**
    -   **Authentication:** Google account login.
    -   **Onboarding:** An AI guide named Pixie provides a tutorial for new users.
    -   **Notifications:** Push notifications for tasks, approvals, status changes, chat messages, GPS alerts, etc. Parents can manage preferences.
    -   **GPS:** GPS check-in, geofencing for safe zones (home, school), notifications for leaving zones or when GPS is disabled. Ability to route to a child's last known location. Integration with Google Maps.
    -   **UI:** Vibrant, fun, interactive, mobile-friendly. Collapsible and draggable sidebar. Comprehensive theme system with light/dark modes and multiple color palettes.
    -   **Welcome Page:** A greeting from Pixie and the tagline A place where keeping up with the day-to-day is no longer a chore within itself.
